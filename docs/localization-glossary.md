# German UI localization glossary

This is the authoritative terminology reference for the on-device German interface and its shared message catalogue. Keep labels concise and natural; translate the meaning, not the English word order.

| English concept | German | Usage |
| --- | --- | --- |
| Wi-Fi / wireless network | WLAN | Use `WLAN`, not a literal expansion; use `SSID` for the technical network identifier. |
| access point | Access Point | Retain the established networking term. |
| IP address | IP-Adresse | German capitalization and hyphenation. |
| Bluetooth | Bluetooth | Protocol and product name; do not translate. |
| MQTT | MQTT | Protocol name; do not translate. |
| home control | Haussteuerung | Generic feature name; distinguish it from the Home Assistant product. |
| wake word | Aktivierungswort | The word that starts voice recognition. |
| settings | Einstellungen | UI section and page title. |
| save | Speichern | Action label. |
| cancel | Abbrechen | Action label. |
| main stream | Hauptstream | Camera/video stream selection. |
| substream | Substream | One word for the lower-bandwidth video stream. |
| Home Assistant | Home Assistant | Product name; do not translate. |
| EchoLocal | EchoLocal | Product name; do not translate. |
